# QRcreator

Aplicación de escritorio desarrollada con **JavaFX** que permite la **generación de códigos QR** a partir de **enlaces**. 
La aplicación ofrece una interfaz sencilla e intuitiva para crear y exportar códigos QR de forma rápida.

## Características

- Aplicación de escritorio desarrollada con **JavaFX**.  
- Generación de **códigos QR** a partir de enlaces.  
- Añadir imágenes en el centro de los **códigos QR**.  
- Interfaz gráfica intuitiva y fácil de usar.  
- Exportación de códigos QR generados.
